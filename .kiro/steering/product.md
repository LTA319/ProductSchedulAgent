# Product Overview

This is a production scheduling agent for machining workshops. It solves job shop scheduling problems using constraint programming to optimize production plans.

Core capabilities:
- Import orders, process routes, and equipment data from Excel
- Automated scheduling using Google OR-Tools CP-SAT solver
- Gantt chart visualization of schedules
- KPI analysis (equipment utilization, on-time delivery, bottleneck identification)
- Web UI for interaction and result export

The system optimizes for minimal makespan (total completion time) while respecting process sequences, equipment constraints, and due dates.

Target users: Production planners in machining/manufacturing environments.

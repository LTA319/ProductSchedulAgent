## 订单数据格式

### 文件要求

- **文件格式**：Excel (.xlsx 或 .xls)
- **工作表名称**：`订单表`
- **表头位置**：第2行（第1行可用于说明或留空）

### 字段说明

| 列名 | 数据类型 | 是否必填 | 说明 | 示例 |
|------|----------|----------|------|------|
| 订单号 | 文本 | 是 | 唯一标识订单的编号 | ORD001 |
| 产品编码 | 文本 | 是 | 产品的唯一标识符，需与工艺路线表中的产品编码对应 | PROD001 |
| 生产数量（件） | 整数 | 是 | 订单需要生产的产品数量，必须大于0 | 10 |
| 承诺交期 | 日期时间 | 是 | 订单的交付截止日期 | 2026-03-15 |
| 优先级（1最高） | 整数 | 是 | 订单优先级，范围1-5，数字越小优先级越高 | 1 |
| 是否急单 | 文本/布尔 | 否 | 标识是否为紧急订单，可填：是/否、True/False、Y/N | 是 |

### 数据示例

```
| 订单号  | 产品编码 | 生产数量（件） | 承诺交期    | 优先级（1最高） | 是否急单 |
|---------|----------|----------------|-------------|-----------------|----------|
| ORD001  | PROD001  | 10             | 2026-03-15  | 1               | 是       |
| ORD002  | PROD002  | 5              | 2026-03-20  | 2               | 否       |
| ORD003  | PROD001  | 8              | 2026-03-18  | 1               | 是       |
```

### 验证规则

- 订单号不能为空且必须唯一
- 产品编码不能为空
- 生产数量必须大于0
- 承诺交期必须是有效的日期格式
- 优先级必须在1-5之间
- 产品编码必须在工艺路线表中存在

## 工艺路线数据格式

### 文件要求

- **文件格式**：Excel (.xlsx 或 .xls)
- **工作表名称**：`工艺路线表`
- **表头位置**：第2行（第1行可用于说明或留空）

### 字段说明

| 列名 | 数据类型 | 是否必填 | 说明 | 示例 |
|------|----------|----------|------|------|
| 产品编码 | 文本 | 是 | 产品的唯一标识符，需与订单表中的产品编码对应 | PROD001 |
| 工序号 | 文本 | 是 | 工序的唯一标识符 | OP001 |
| 工序名称 | 文本 | 是 | 工序的描述性名称 | 粗加工 |
| 工序顺序 | 整数 | 是 | 工序在工艺路线中的顺序，从1开始连续编号 | 1 |
| 单件标准工时（分钟） | 数值 | 是 | 完成单件产品该工序所需的标准时间，单位为分钟 | 120 |
| 可使用设备编号 | 文本 | 是 | 可以执行该工序的设备编号，多个设备用逗号分隔 | EQ001,EQ002 |

### 数据示例

```
| 产品编码 | 工序号 | 工序名称 | 工序顺序 | 单件标准工时（分钟） | 可使用设备编号 |
|----------|--------|----------|----------|----------------------|----------------|
| PROD001  | OP001  | 粗加工   | 1        | 120                  | EQ001          |
| PROD001  | OP002  | 精加工   | 2        | 90                   | EQ002          |
| PROD001  | OP003  | 检验     | 3        | 30                   | EQ003          |
| PROD002  | OP004  | 铣削     | 1        | 150                  | EQ004          |
| PROD002  | OP005  | 钻孔     | 2        | 60                   | EQ005          |
```

### 验证规则

- 产品编码不能为空
- 工序号不能为空
- 工序名称不能为空
- 工序顺序必须大于0，且同一产品的工序顺序应连续（1, 2, 3...）
- 单件标准工时必须大于0
- 可使用设备编号不能为空，且设备必须在设备表中存在
- 同一产品的工序按顺序执行（工序顺序小的先执行）

## 设备数据格式

### 文件要求

- **文件格式**：Excel (.xlsx 或 .xls)
- **工作表名称**：`设备表`
- **表头位置**：第2行（第1行可用于说明或留空）

### 字段说明

| 列名 | 数据类型 | 是否必填 | 说明 | 示例 |
|------|----------|----------|------|------|
| 设备编号 | 文本 | 是 | 设备的唯一标识符 | EQ001 |
| 状态 | 文本 | 是 | 设备当前状态，只有"可用"状态的设备会被使用 | 可用 |
| 每日工作小时 | 数值 | 是 | 设备每天可工作的小时数，必须大于0 | 8 |

### 数据示例

```
| 设备编号 | 状态 | 每日工作小时 |
|----------|------|--------------|
| EQ001    | 可用 | 8            |
| EQ002    | 可用 | 8            |
| EQ003    | 可用 | 8            |
| EQ004    | 维修 | 0            |
| EQ005    | 可用 | 10           |
```

### 验证规则

- 设备编号不能为空且必须唯一
- 状态不能为空
- 每日工作小时必须大于0
- 只有状态为"可用"的设备会被纳入排程计算

## 数据验证规则

### 引用完整性

系统会自动验证以下引用关系：

1. **订单 → 工艺路线**：订单表中的每个产品编码必须在工艺路线表中存在
2. **工艺路线 → 设备**：工艺路线表中的可使用设备编号必须在设备表中存在且状态为"可用"

### 数据一致性

1. **工序顺序连续性**：同一产品的工序顺序应该是连续的整数（1, 2, 3...）
2. **订单号唯一性**：订单表中不能有重复的订单号
3. **设备编号唯一性**：设备表中不能有重复的设备编号

### 数据范围

1. **数量限制**：生产数量必须大于0
2. **优先级范围**：优先级必须在1-5之间
3. **工时限制**：标准工时必须大于0
4. **产能限制**：每日工作小时必须大于0

## 常见问题

### Q1: 为什么我的数据上传后显示"文件无法读取"？

**A**: 请检查以下几点：
- 文件格式是否为 .xlsx 或 .xls
- 工作表名称是否正确（订单表、工艺路线表、设备表）
- 表头是否在第2行
- 文件是否损坏或被其他程序占用

### Q2: 什么是"工序顺序"？

**A**: 工序顺序定义了产品加工的先后关系。例如，工序顺序为1的工序必须在工序顺序为2的工序之前完成。系统会自动确保工序按顺序执行。

### Q3: 可以让一个工序在多台设备上执行吗？

**A**: 可以。在"可使用设备编号"列中，用逗号分隔多个设备编号（如：EQ001,EQ002）。系统会自动选择最优的设备分配方案。

### Q4: 如何处理设备维护或停机？

**A**: 将设备的状态设置为"维修"或其他非"可用"状态，系统会自动跳过该设备。

### Q5: 标准工时的单位是什么？

**A**: 工艺路线表中的标准工时单位是**分钟**。系统会自动将其转换为小时进行计算。

### Q6: 交期格式有什么要求？

**A**: 交期可以是以下格式：
- 日期：2026-03-15
- 日期时间：2026-03-15 14:30
- Excel 日期格式

### Q7: 如果订单的产品没有工艺路线会怎样？

**A**: 系统会在数据验证阶段报错，提示"以下产品在订单中存在但缺少工艺路线"。您需要在工艺路线表中添加该产品的工艺路线。

### Q8: 优先级如何影响排程？

**A**: 当前版本主要以最小化总完工时间为优化目标。优先级信息已被记录，可在未来版本中用于多目标优化。

### Q9: 系统支持多少订单和设备？

**A**: 理论上没有限制，但求解时间会随问题规模增加。建议：
- 小规模：10-20个订单，5-10台设备（求解时间 < 10秒）
- 中等规模：20-50个订单，10-20台设备（求解时间 < 60秒）
- 大规模：50+个订单（可能需要较长求解时间或分批处理）

### Q10: 如何导出排程结果？

**A**: 排程完成后，在界面上点击"下载排程结果"按钮，可以选择导出为 Excel 或 CSV 格式。导出的文件包含每个工序的订单号、工序编号、设备编号、开始时间、结束时间和持续时间。
